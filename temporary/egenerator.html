Main Ideas

Email generator was my first personal project(keeping the ownership admitted) during my internship. This was made for the web developers who need to create HTML email layout repeatedly for different clients.
Using Bootstrap for a quick styling, Symfony as it was requirement from the company, and Docker to be able to recreate environment easily.

Keywords

Target Audience

Developers who need to create HTML emails repeatedly.

Business owners who want to create HTML emails without special knowledge.

Functions

  1. Users can choose the email layout easily, by clicking and choosing different shapes.
  2. Users can choose key colors, font family (either fully customized or choose from list), and the font size for further customization.
  3. Users can copy the HTML code in one click, paste in their projects. Simply replacing images and text to be able to use.
