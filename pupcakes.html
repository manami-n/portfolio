Main Ideas

This was my final project for Web application development course. The idea is to make a web service where people can find the places to eat with their pets (mainly dogs). Using OpenStreetMap API with Leaflet to generate map, and user can sign-up to make their favorite list or suggest a new place.

Keywords

  • Pet
  • Friendly
  • Community
  • Map

Target Audience

Pets' owners in Barcelona who want to go out more with their pets.

Gastronomy businesses which want to promote their pet-friendliness.

Functions

  1. User can easily find a pet-friendly places by name, through the map, or just near-by location. They can filter the places by category, reservation requirement, and etc.
  2. User can also register Pupcakes in order to make their own favorite place list. Simply clicking heart icon to add or remove.
  3. User can share a new restaurant by sending a suggestion. Suggested places appears as "Suggested" category instead of "Verified" category.
